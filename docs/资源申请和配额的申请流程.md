# 应龙平台资源申请与配额管理需求文档

## 一、文档目的



1. 试用资源申请流程：申请完成后，由应龙平台分配 IP、账号，并明确到期期限和回收规则。
2. 正式资源申请流程：申请完成后，开通账号权限、授权集群部署权限，并按用户权限限制可见集群、可操作集群、可见服务和可用资源。

## 三、角色定义

| 角色 | 说明 | 主要操作 |
| ---- | ---- | -------- |
| 申请人 | 业务方或模型部署需求方 | 发起试用资源申请、正式资源申请、查看自己的申请和资源 |
| 部署操作人 | 实际登录平台部署模型服务的人员 | 使用授权账号部署、查看、维护自己的模型服务 |
| 审核管理员 | 应龙平台管理员或资源管理员 | 审核申请、分配 IP、账号、资源配额、集群权限 |



## 五、总体流程

应龙平台资源申请分为两类：

1. 试用资源申请：用于短期验证、线下部署、临时测试，到期后需要回收。
2. 正式资源申请：用于试用通过后的长期部署、平台正式运行和生产使用。

```text
申请人提交申请
  -> 管理员审核
  -> 分配 IP / 账号 / 集群 / 资源配额
  -> 用户登录平台使用资源
  -> 平台按权限控制可见范围和操作范围
  -> 到期提醒 / 延期 / 回收 / 正式运行
```

## 六、试用资源申请

### 6.1 使用场景

试用资源申请用于以下场景：

1. 非主线模型临时试部署。
2. 业务方验证模型效果。
3. 第三方模型、开源模型、自研模型的短期测试。
4. 模型部署需求方需要临时使用 GPU、IP、账号或测试环境。

试用资源不用于正式生产服务，不承诺长期稳定运行。

### 7.5 审核通过后的系统动作

正式资源申请审核通过后，应龙平台应完成：

1. 开通或绑定用户平台账号。
2. 授权用户访问指定集群。
3. 授权用户在指定集群的部署权限。
5. 建立用户与集群、资源配额的绑定关系。
6. 建立用户与服务资源的可见和操作范围。

正式资源开通通知应包含：

| 信息 | 说明 |
| ---- | ---- |
| 平台账号 | 用户登录应龙平台的账号 |
| 授权集群 | 用户被授权访问和操作的集群 |
| 命名空间/项目空间 | 用户可部署服务的空间 |
| 资源配额 | GPU、CPU、内存、存储 |
| 权限范围 | 查看、部署、更新、删除、日志、监控等 |
| 生效时间 | 权限生效时间 |
| 运维责任 | 用户需维护自己部署的模型服务 |

## 八、权限控制需求

### 8.1 集群权限控制

用户只能查看和操作被授权的集群。

规则如下：

| 场景 | 权限规则 |
| ---- | -------- |
| 集群列表 | 只展示当前用户已授权的集群 |
| 集群详情 | 用户只能进入已授权集群详情 |
| 未授权集群 | 不展示；如通过 URL 访问，应提示无权限 |
| 集群资源统计 | 只统计用户已授权集群范围内的数据 |
| 集群部署操作 | 只能在授权集群内执行部署操作 |

原型要求：

1. 集群选择下拉框只显示授权集群。
2. 未授权集群不出现在列表、筛选器、部署页和资源选择页。
3. 如果用户没有任何授权集群，页面显示“暂无授权集群，请先提交正式资源申请”。

### 8.2 服务可见性控制

用户只能查看和操作当前用户自己的服务，或被授权项目内的服务。

默认规则：

1. 普通用户只能查看自己创建的服务。
2. 普通用户只能操作自己创建的服务。
3. 管理员可查看和操作全部服务。

服务列表权限规则：

| 场景 | 普通用户 | 管理员 |
| ---- | -------- | ------ |
| 查看服务列表 | 仅自己的服务 | 全部服务 |
| 查看服务详情 | 仅自己的服务 | 全部服务 |
| 更新服务 | 仅自己的服务 | 全部服务 |
| 删除服务 | 仅自己的服务 | 全部服务 |
| 查看日志 | 仅自己的服务 | 全部服务 |
| 查看监控 | 仅自己的服务 | 全部服务 |

原型要求：

1. 服务列表默认过滤当前用户自己的服务。
2. 不显示其他用户服务。
3. 如通过 URL 访问其他用户服务详情，应提示无权限。

### 8.3 服务部署资源可见性控制

用户在创建或部署服务时，只能看到当前授权集群下的资源。

规则如下：

| 场景 | 权限规则 |
| ---- | -------- |
| 选择集群 | 只能选择已授权集群 |
| 选择资源 | 只能看到所选授权集群下的可用资源 |
| 选择 GPU 类型 | 只展示该集群内已授权或可申请的 GPU 类型 |

原型要求：

1. 服务部署页选择集群。
2. 集群选择后，资源规格、GPU 类型、
3. 未授权集群的资源不展示。

## 十一、后端校验要求

前端隐藏未授权资源不能替代后端权限校验。后端必须校验：

1. 当前用户是否有目标集群权限。
3. 当前用户是否有部署操作权限。
4. 当前用户申请的资源是否超过配额。
5. 当前用户是否有权限查看或操作目标服务。
6. 试用资源是否已过期。
7. 账号或权限是否已被回收。
