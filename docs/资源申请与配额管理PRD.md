| 项目 | 内容 |
| --- | --- |
| 产品模块 | 运维管理 / 资源申请 |
| 适用平台 | 应龙大模型推理平台 |

## 2. 背景与目标

应龙平台需要统一管理模型部署相关的资源申请、审批、资源分配、账号权限开通、配额绑定和到期回收。资源申请分为两类：

1. 试用资源申请：用于短期验证、线下部署、临时测试。审核通过后分配线下服务器资源，由业务方或模型需求方线下登录服务器部署；到期后回收资源。
2. 正式资源申请：用于试用通过后的长期部署、平台正式运行和生产使用。审核通过后开通平台账号、资源范围和资源配额，用户登录应龙平台自助部署。

本 PRD 的目标是明确平台需要提供的页面、字段、流程、权限控制、后端校验和验收标准。

## 4. 角色与权限

| 角色 | 说明 | 核心权限 |
| --- | --- | --- |
| 申请人 | 业务方或模型部署需求方 | 发起申请、保存草稿、提交申请、查看本人申请、查看审批结果 |
| 部署操作人 | 实际登录服务器或平台部署模型服务的人 | 查看被授权资源、线下登录服务器试用部署、登录平台正式部署、维护本人服务 |
| 审核管理员 | 平台管理员或资源管理员 | 审核申请、驳回申请、分配试用资源、开通正式账号权限、配置配额、回收资源 |
| 系统管理员 | 超级管理员 | 查看全部申请、维护全部资源、处理权限异常、配置全局规则 |

## 5. 总体业务流程

### 5.1 申请单审批流

```text
保存草稿
  -> 提交申请（已提交）
  -> 管理员受理（审核中）
  -> 审核通过 / 已驳回
```

流程说明：

1. 申请人可先保存草稿，草稿不进入管理员审批列表。
2. 申请人提交申请后，申请单状态变为已提交。
3. 审核管理员在审批列表中直接点击审核，打开审核弹窗处理申请。
4. 管理员受理后状态为审核中。
5. 审核通过后，按申请类型完成试用资源分配或正式资源分配。
6. 已驳回时必须填写驳回原因，并退回申请人修改后重新提交。

### 5.2 试用资源申请流程

```text
申请
  -> 审核通过
  -> 线下登录服务器部署
  -> 到期回收资源
```

流程说明：

1. 申请人提交试用资源申请，说明业务系统、试用目的、部署操作人、GPU 型号、GPU 数量和试用周期。
2. 审核管理员审核资源合理性和试用周期。
3. 审核通过后，管理员分配线下服务器、IP、账号或登录方式、GPU 资源和到期时间。
4. 部署操作人线下登录服务器，自行完成模型部署、依赖适配、启动、接口暴露、效果验证和资源评估。
5. 资源到期前平台提醒申请人和部署操作人。
6. 到期后管理员执行资源回收；如需继续使用，申请人应提交延期或正式资源申请。

### 5.3 正式资源申请流程

```text
申请
  -> 审核通过，开通账号
  -> 登录平台部署
```

流程说明：

1. 申请人提交正式资源申请，说明模型名称、试用结论、上线计划、GPU 配额、预计 QPS/并发等信息。
2. 审核管理员审核是否满足正式接入条件和资源配额要求。
3. 审核通过后，平台开通或绑定用户账号。
4. 管理员授权用户访问指定集群
5. 部署操作人登录应龙平台，在授权范围内自助部署、更新、查看日志和监控。
6. 用户负责正式服务的后续维护、版本升级、参数调整和下线。

## 6. 页面规划

### 6.1 资源申请列表页

入口：`运维管理 / 资源申请`

页面目标：统一展示当前用户可见的试用资源申请和正式资源申请。

核心功能：

| 功能 | 说明 |
| --- | --- |
| 新建试用申请 | 点击后打开试用资源申请弹窗 |
| 新建正式申请 | 点击后打开正式资源申请弹窗 |
| 类型筛选 | 全部、试用资源、正式资源 |
| 状态筛选 | 草稿、已提交、审核中、已驳回、审核通过 |
| 关键词搜索 | 按申请名称、业务系统、模型名称搜索 |
| 申请列表 | 展示申请名称、类型、资源、授权/分配范围、状态、更新时间、操作 |
| 操作 | 查看、复制申请、撤回、删除 |

列表字段：

| 字段 | 说明 |
| --- | --- |
| 申请名称 | 申请单标题 |
| 申请类型 | 试用资源 / 正式资源 |
| 业务系统 | 使用资源的业务系统 |
| 申请人 | 当前申请发起人 |
| 部署操作人 | 实际部署人员 |
| 资源需求 | 填写GPU 型号和GPU 数量，最终结论不一定按申请可完全分配 |
| 授权/分配范围 | 试用显示服务器/IP，正式显示集群 |
| 状态 | 当前申请状态 |
| 到期时间 | 试用资源必填，正式资源可为空 |
| 操作 | 查看、编辑、复制、撤回、删除 |

### 6.2 新建试用资源申请弹窗

页面目标：支持业务方申请短期线下验证资源。

表单字段：

| 分类 | 字段 | 必填 | 说明 |
| --- | --- | --- | --- |
| 基本信息 | 申请名称 | 是 | 例如：XX 模型试用资源申请 |
| 基本信息 | 申请部门/项目组 | 是 | 资源所属部门或项目 |
| 基本信息 | 业务系统 | 是 | 使用资源的业务系统 |
| 基本信息 | 申请人 | 是 | 默认当前登录用户，可修改 |
| 基本信息 | 部署操作人 | 是 | 实际线下登录服务器部署的人 |
| 资源需求 | GPU 型号 | 是 | 华为 910B4、英伟达 L40、英伟达 A10、不限制 |
| 资源需求 | GPU 数量 | 是 | 申请 GPU 卡数 |
| 周期管控 | 计划开始时间 | 是 | 试用开始时间 |
| 周期管控 | 计划结束时间 | 是 | 试用结束时间 |
| 备注 | 其他说明 | 否 | 依赖、网络、账号、端口等补充说明 |

操作按钮：

| 按钮 | 行为 |

## 7. 状态设计

### 7.1 申请单状态

```text
草稿
  -> 已提交
  -> 审核中
  -> 已驳回
  -> 审核通过
```

状态说明：

| 状态 | 说明 |
| --- | --- |
| 草稿 | 已保存但未提交 |
| 已提交 | 申请已提交，等待管理员处理 |
| 审核中 | 管理员正在审核 |
| 已驳回 | 管理员驳回申请 |
| 审核通过 | 申请通过，等待或已完成资源分配 |

## 8. 权限控制需求

### 8.1 集群权限控制

| 场景 | 权限规则 |
| --- | --- |
| 集群列表 | 只展示当前用户已授权集群 |
| 集群详情 | 只能进入已授权集群详情 |
| 未授权集群 | 不展示；通过 URL 访问时提示无权限 |
| 部署操作 | 只能在授权集群内执行 |

### 8.3 服务可见性控制

| 场景 | 普通用户 | 管理员 |
| --- | --- | --- |
| 查看服务列表 | 仅本人服务或授权项目服务 | 全部服务 |
| 查看服务详情 | 仅本人服务或授权项目服务 | 全部服务 |
| 更新服务 | 仅本人服务或授权项目服务 | 全部服务 |
| 删除服务 | 仅本人服务或授权项目服务 | 全部服务 |

### 8.4 部署资源可见性控制

| 场景 | 权限规则 |
| --- | --- |
| 选择集群 | 只能选择已授权集群 |
| 选择资源 | 只能看到授权集群下可用资源 |
