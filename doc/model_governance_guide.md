# 应龙平台模型纳管操作指引

版本：V1.0  
适用对象：需要申请试用或正式资源并纳管非主线模型的业务团队。

## 1. 申请前确认

1. 在“主线模型目录”确认现有公共模型无法满足业务需求。
2. 明确业务系统、调用场景、预估调用量和期望上线时间。
3. 完成模型授权确认，并指定业务负责人和技术负责人。

## 2. 试用验证

1. 在模型纳管页面提交“试用资源申请”。
2. 获批后完成模型启动、依赖适配、接口封装和效果验证。
3. 记录 GPU 型号及数量、显存占用、并发、吞吐和响应时延。
4. 试用结束后按期释放资源；需要长期运行时进入正式申请。

## 3. 准备纳管材料

按照《应龙平台模型纳管规范》准备模型信息、权重、镜像、Kubernetes YAML、接口文档、性能报告和测试样例，并确保版本信息一致。

## 4. 正式资源申请

1. 提交“正式资源申请”，填写业务价值、模型信息和资源需求。
2. 上传或提供纳管材料地址，说明试用结论和容量测算依据。
3. 跟踪审批结果；如被驳回，根据审批意见补充材料后重新提交。

## 5. 部署与维护

权限和配额开通后，由业务方完成部署、发布、升级和调优，并持续关注运行监控与告警。发生版本变更、资源扩缩容或下线时，应同步更新申请信息。
